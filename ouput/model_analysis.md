# 销售额预测建模分析

## 1. 输入与输出

### 输出（预测目标）

| 选项 | 预测目标 | 粒度 | 适用场景 |
|------|---------|------|---------|
| **A：时间序列预测** | 未来某月/某季的总销售额 | 月度聚合 | 宏观趋势预测、经营规划 |
| **B：回归预测** | 每条订单明细的销售额 | 明细行级别 | 微观单品销售预测 |

题目要求预测"零售销售额"，且评估指标为 MSE/MAE/MAPE，两种粒度均可。建议**以 A 为主**（时间序列），因为题目建议了"时间序列分析"且给出按时间划分训练/测试集；也可用 B 丰富分析维度。

### 输入特征

#### A：时间序列模型输入

| 特征类别 | 具体特征 | 来源 |
|---------|---------|------|
| 滞后特征 | 前 1-12 个月的销售额 (lag_1 ~ lag_12) | 历史聚合 |
| 时间特征 | 月份 (1-12)、季度 (1-4)、年份 | Order Date |
| 季节特征 | 是否年末旺季、是否月初/月末 | 衍生 |
| 滚动统计 | 过去 3/6/12 个月的滚动均值、标准差 | 历史聚合 |

#### B：回归模型输入

| 特征类别 | 具体特征 | 取值数 | 类型 |
|---------|---------|--------|------|
| **产品维度** | Category | 3 | 分类 |
| | Sub-Category | 17 | 分类 |
| **客户维度** | Segment | 3 | 分类 |
| **地理维度** | Region | 4 | 分类 |
| **物流维度** | Ship Mode | 4 | 分类 |
| **时间维度** | Year, Quarter, Month, DayOfWeek | - | 数值/分类 |
| | IsHolidaySeason | 2 | 二值 |
| **衍生特征** | ShippingDays | - | 数值 |
| | OrderSize (该订单商品数) | - | 数值 |

## 2. 可选模型对比

### 时间序列模型

| 模型 | 优点 | 缺点 | 适用性 |
|------|------|------|--------|
| **ARIMA/SARIMA** | 经典、可解释强、适合单变量 | 需数据平稳、对季节周期要求高 | ★★★★ 适合月度预测，数据有 12 月周期 |
| **Prophet (Facebook)** | 自动处理季节/节假日、鲁棒性强 | 需安装、调参 | ★★★★★ 最适合，数据有明显年度周期+年末峰值 |
| **Holt-Winters (指数平滑)** | 简单、快速、适合含趋势+季节的数据 | 仅加法/乘法两种模式 | ★★★★ 数据趋势+季节明显 |
| **XGBoost/LightGBM (特征工程时序)** | 可加入多特征、精度高 | 需特征工程、易过拟合 | ★★★★ 适合加入外部特征 |

### 回归/机器学习模型

| 模型 | 优点 | 缺点 | 适用性 |
|------|------|------|--------|
| **线性回归** | 简单、可解释、基线模型 | 难以捕捉非线性关系 | ★★★ 适合作为 baseline |
| **决策树** | 可解释、处理分类变量好 | 易过拟合 | ★★★ |
| **随机森林** | 鲁棒、特征重要性可解释 | 对极端值敏感 | ★★★★ 推荐，适合混合类型特征 |
| **XGBoost/LightGBM** | 精度最高、处理缺失值好 | 调参复杂、易过拟合 | ★★★★★ 推荐，竞赛首选 |

## 3. 推荐方案

### 主方案：时间序列预测（宏观）

```
月度聚合销售额 → Prophet / SARIMA → 预测 2026 年月度销售额
```

- 将数据按月聚合，得到 2022.01 ~ 2025.12 共 **48 个月**的月度销售额序列
- 用前 36 个月训练，后 12 个月验证
- Prophet 自动处理趋势、年周期、周周期，且对节假日（年末旺季）有内置支持

### 辅方案：回归预测（微观）

```
明细行特征(品类/区域/客群/时间) → XGBoost / 随机森林 → 预测单行销售额
```

- 用 2022-2024 数据训练，预测 2025 年每一行的销售额
- 用特征重要性分析找出关键驱动因素
- 可叠加聚合得到月度预测，与时间序列方案交叉验证

### 模型评估

| 指标 | 含义 | 目标 |
|------|------|------|
| MSE | 均方误差，惩罚大误差 | 越小越好 |
| MAE | 平均绝对误差，直观易理解 | 越小越好 |
| MAPE | 平均绝对百分比误差，相对误差 | < 30% 为可接受 |

## 4. 数据预处理要点

| 步骤 | 处理方式 |
|------|---------|
| 缺失值 | Postal Code 11 条缺失 → 用所在州的众数填充 |
| 编码 | 分类变量 → One-Hot / Label Encoding |
| 日期解析 | Order Date / Ship Date → datetime |
| 特征衍生 | Year/Month/Quarter/DayOfWeek/ShippingDays/OrderSize/IsHolidaySeason |
| 训练/测试划分 | 2022-2024 训练，2025 测试（严格按时间，避免数据泄露） |
| 聚合去重 | 订单级分析时需按 Order ID 聚合，避免同订单多条明细重复计算 |
