数据清洗说明
================
文件: clean_data.py
输入: data.csv
输出: data_cleaned.csv

检测到以下数据质量问题并已处理：

一、发货日期早于订单日期（42条）
----------------------------------------
问题描述: 42条记录的 Ship Date（发货日期）年份为2019，
但 Order Date（订单日期）为2025年12月25日-30日。
Ship Date的日/月与实际一致，但年份录入错误（2019应为2026）。

处理方式: 将 Ship Date 年份从 2019 改为 2026。
修正后发货间隔为3-11天，与数据集中同 Ship Mode 的发货周期一致。

示例: RowID=271, Order=28/12/2025, Ship=02/01/2019 -> 02/01/2026

二、Postal Code 缺失（11条）
----------------------------------------
问题描述: 11条记录的 Postal Code 为空，均来自 Burlington, Vermont。

处理方式: 查询 Burlington, Vermont 的美国邮编为 05401，统一填充。

三、邮编格式不统一（429条）
----------------------------------------
问题描述: 429条记录邮编为4位数字（如 2908），缺少前导零。

处理方式: 使用 zfill(5) 统一补零为5位标准格式（如 2908 -> 02908）。

四、未处理（属于正常业务特征，非数据错误）
----------------------------------------
- Sales 右偏分布（均值230.77 >> 中位数54.50）: 零售数据天然特征，
  属正常长尾分布，不应剔除异常值，建模时建议做对数变换。
- Sales 无负数、无零值：数据正常。
- 无完全重复行：数据正常。
